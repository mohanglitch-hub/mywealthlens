# MyWealthLens

**Personal Wealth Management Platform for Indian Investors**

MyWealthLens helps individuals and families track, plan, and grow their wealth in one place. It is designed specifically for the Indian financial ecosystem
(mutual funds, stocks, insurance, retirement, and family wealth transfer).

---

## Current Status

This project is under active development (approximately 75% complete).  
Core modules for investments, goals, and family planning are functional. Some advanced features are still being refined.

---

## Key Features

- **Wealth Centre**: Track mutual funds (CAS support + XIRR), stocks, and overall portfolio performance
- **Goal Planning**: Set financial goals with glide-path projections
- **Family Centre**: Manage family members, relationships, and intended heirs
- **Insurance Centre**: Track insurance policies
- **Retirement Centre**: Retirement planning tools
- **Tradebook & Transaction History**

## How to Run Locally

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `python app.py`
4. Open your browser at `http://localhost:5000` (or the port shown)

## Project Structure

- `wealth/` – Investment and portfolio related features

- `insurance_centre/` – Insurance tracking

- `templates/` – Frontend pages
